# 样例：顶替

<!-- Claude Generated -->

针对装箱侧最易写出的一类"先数到期数、再按名额消费"的实现：閏土在批内第一个消费、给自己排 −8 的条目立即到期并按触发刻排到既有条目之前——名额被挤占，批尾的既有条目被推迟到下一刻。五层柱构造与閏土样例相同，专攻装箱的 java.util.PriorityQueue 形态（含 for-each 类误用）；受害线是一只出现时间 0 的受害猹。

## 布局与计划

列1 五层柱与閏土相同（层1 猹8 参照 / 閏8 / 种植位 / 观察者闰1 / 猹8 参照），受害猹0 在 [1,1,2]。测试时段 `[0,9]`。

| 条目 | 位置 | 时 | 创时 | 级 | 职责 |
|---|---|---|---|---|---|
| 閏土 | [2,1,1] | 0 | 0 | 危急0 | 批首消费，给自己排 −8 挤进队头 |
| 受害猹 | [1,1,2] | 0 | 0 | 松弛15 | 批尾的既有条目，出现时间 0 |
| 观察者闰 | [4,1,1] | 2 | 0 | 缺省 | 断言种植已发生 |
| 猹×3 | 层1/3/5 列1 | 8 | 0 | 松弛15 | 清参照与种猹（出现时间 8） |

## 时间线（正确路径）

t=0：整批先出队再消费——閏土与受害猹一同出队；閏土消费时给自己排 −8、种猹8，新条目进入队列但不挤占本批；受害猹当刻消费（低四位 0）自清；后续批次把自计划再次收集（或全序留到 t=1 收集），断言臂 层3猹8==层1猹8 过。t=2 观察者过。t=8 清场。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 先数到期数再按名额 poll（自计划条目按触发刻 −8 排到受害猹之前、耗尽名额） | 受害猹被推迟到 t=1 消费，1≠0——[1,1,2] 幸存 |
| 消费中对队列 for-each 迭代 | ConcurrentModificationException，当场崩溃报错 |
| 閏土未消费或种植未发生 | t=2 观察者断言 猹8 对 〇——立即红 |

## 设计要点与边界

- 受害猹只设一只（多只违反"小"）；其出现时间 0 在窗口 [0,9) 内无同余重现（1..8 均不同余）。
- 三前提、二态双绿构造与四条残余同閏土样例，见 閏土.md，不再复述。
