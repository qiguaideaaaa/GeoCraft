# 样例：大存储值

<!-- Claude Generated -->

打包专属：堆内同时存在高位为 0 与高位为 1 的存储值时，排序与出队判断必须按无符号进行。存储值 = （入队时刻 − 基准时间）+ delay，本样例用"钉基准时间 + 时钟跳跃 + 同刻双入队"把两个条目的存储值分别放在 2^31 分界两侧。另配一对严重过期的讯→猹，用两者的消费顺序确认"消费前未发生重设基准时间"这一前提——若重设提前发生，跨分界的局面根本不存在，样例就成了前提落空的绿。

## 布局与计划

单层两行：第 1 行 `猹0猹1猹3`（列1 钉基准，列2、列3 为存储值线），第 2 行 `讯e猹f`（顺序检查线，讯朝东指向猹f）。记 E = 2147483632（2^31−16，低四位为 0）。

| 条目 | 位置 | 时 | 创时 | 级 | 存储值 |
|---|---|---|---|---|---|
| 钉基准 | 行1列1 猹0 | 0 | 0 | 缺省中上7 | 0 |
| 小存储值 | 行1列2 猹1 | E+1 | E | 缺省中上7 | 2147483633（2^31−15，高位 0） |
| 大存储值 | 行1列3 猹3 | E+19 | E | 缺省中上7 | 2147483651（2^31+3，高位 1） |
| 顺序检查·讯 | 行2列1 | 5 | 0 | **中下8** | 5 |
| 顺序检查·猹 | 行2列2 猹f | 9 | 0 | 缺省中上7 | 9 |

测试时段 `[0,1]`、`[E, E+20]`。大存储值条目的触发刻特意取低四位为 3（≠ E 的低四位 0）：任何把它提前放行到 t=E 的故障都会撞上 0≠3 而留下幸存猹——若取低四位 0，提前放行与按时消费在自清判据下无法区分。

## 时间线（正确路径）

- **t=0**：钉基准条目入队——队列在此创建，基准时间被钉在 0——并当刻消费（低四位 0，猹0 自清）。删去这一条，后续条目入队时基准时间会被设成入队时刻，存储值缩水，全样例失去意义。顺序检查线两条同刻入队（存储值 5、9），窗口内为未来，不消费。
- **t=E**：存储值线两条同刻入队。入队时距基准时间 2^31−16，未触发重设基准时间。此刻堆里 2147483633 与 2147483651 并存，无符号序前者在前；顺序检查线两条已严重过期，按存储值序先讯后猹出队：讯把猹f 拨成猹0，随后猹f 位置的计划消费（低四位 0）自清。
- **t=E+1**：低四位为 1，小存储值条目出队，猹1 自清。
- **t=E+19**：距基准时间 2^31+3，大存储值条目出队，低四位为 3，猹3 自清。全场清空。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 消费前发生了重设基准时间（如入队时重设条件写错、或随意重设） | 顺序检查线两条被一并归 0，顺序改由存储值低位决定——讯的优先级（中下8）故意排在猹（中上7）之后，顺序反转：猹f 先被消费（f≠0 不自清）再被讯拨成猹0——行2列2 幸存 |
| 堆排序误用有符号（大存储值按有符号为负、被顶到堆根） | 出队判断在堆根就停下，其余条目全部被埋到 t=E+19 才放行——行1列2 猹1（低四位 3≠1）与行2列2（讯迟到 E+19 拨后为猹0，3≠0）幸存 |
| 出队判断误用有符号（存储值 2^31+3 被当成负数放行） | 大存储值条目在 t=E+1（小存储值出队后轮到堆根）被放行，低四位 1≠3——行1列3 猹3 幸存 |
| 堆排序与出队判断同时误用有符号 | 大存储值条目在 t=E 就被放行，低四位 0≠3——行1列3 猹3 幸存 |
| 存储值构造错误（如漏加入队时刻与基准时间的差） | 触发刻整体错位，消费时刻的低四位与出现时间不同余——对应猹幸存 |
| 大存储值条目丢失 | 行1列3 猹3 幸存 |
| 顺序检查·讯丢失 | 猹f 无人拨动，消费时 f≠0——行2列2 幸存 |

## 设计要点

- 顺序检查线的优先级安排是关键：正常路径顺序由存储值高位（5 对 9）决定，优先级不参与；重设归 0 后高位抹平，低位的优先级位接管——讯（中下8）落到猹（中上7）之后，反转即红。级位以下的坐标与方块 ID 位上限不足 1<<28，盖不过级位。
- "入队即消费"型退化由存储值线自身检出：小存储值在 t=E 提前消费低四位 0≠1，大存储值 0≠3，均幸存。顺序检查线在 t=0 的提前消费恰好同余（讯先拨 f→0、低四位 0）不可见，无妨。
- 窗口 `[E, E+20]` 共执行 20 刻，超过 16，窗口内有三个同余重现点：猹1 在 t=E+17、猹3 在 t=E+3、猹f 初态 f 在 t=E+15。三者不可见都需要"消费被延迟/提前恰好特定刻数"或与讯丢失叠加的复合故障，接受。
- 时间差验算：`1−0 = 1`，`(E+20)−E = 20`，均为小正数。
