# 样例：中途重设

<!-- Claude Generated -->

打包专属：重设基准时间发生在**消费中途**（由方块的中途 schedule 触发）时，队内既有未来条目的触发刻必须被精确重算、跨重设的自计划必须照常准点。与重设基准时间样例分工：那边验证**注入阶段**重设的过期条目归 0 与截断，这边验证**消费阶段**重设对未来条目与已入队未执行的自计划的无损性。

一个推演得出的事实：在本样例这类单区块、单批（到期条目 ≤ 批上限 100）的规模下，消费阶段的重设只面对未来条目——到期条目在本刻批次开头就已全部出队；归 0 钳制在此规模下只在注入阶段可达，已由重设基准时间样例覆盖。到期条目超过批上限、或消费中跨区块入队触发他区块重设时，钳制路径在消费阶段仍可达，本样例不覆盖。所以本样例的受害线全部是未来条目。

## 布局与计划

列1 五层柱与闰土复种相同（层1 猹2 参照＝二代状态 / 闰2 / 种植位 / 观察者闰1 / 猹2 参照），受害猹0 在 [1,1,2]。记 M = 2147483536（2^31−112，低四位 0）、J = M+238 = 2147483774（低四位 14）。测试时段 `[0,1]`、`[M, M+1]`、`[J, J+5]`。

| 条目 | 位置 | 时 | 创时 | 级 | 职责 |
|---|---|---|---|---|---|
| 重设引信闰 | [2,1,1] | M+1 | 0 | 缺省 | 见下：J 刻消费、给自己排 +2 触发重设 |
| 受害猹 | [1,1,2] | J+2 | M | 松弛15 | 重设前入队的未来条目 |
| 猹 | [3,1,1] | J+2 | M | **危急0** | 复种前清一代种猹 |
| 观察者闰 | [4,1,1] | J+2 | M | 松弛15 | 断言二代已就位 |
| 猹 | [1,1,1] | J+4 | M | 松弛15 | 清参照 |
| 猹 | [3,1,1] | J+4 | **J+3** | 松弛15 | 清二代种猹 |
| 猹 | [5,1,1] | J+4 | M | 松弛15 | 清参照 |

三个时段各司其职：`[0,1]` 只做注入——引信的延迟 M+1 恰好装得进 int，且触发刻落在时段二的终点刻上；`[M, M+1]` 注入五条创时 M 的未来条目（此刻距基准时间 M < 2^31−1，注入不触发重设，且它们的延迟 240/242 装得进 int——这是它们不能在 t=0 注入的原因）；`[J, J+5]` 执行。**J 刻零注入**是硬约束：任何创时 J 的条目会在注入阶段先行触发重设，引信到场时重设早已发生、前提落空。

创时表：(层3,猹) 键——危急0【创M → J+2】、二代清【创J+3 → J+4】不相交；(层2,闰) 键——引信【创0 → J】、一代自计划【J → J+2】、二代【J+2 → J+4】首尾相接；J+3 的注入距新基准时间仅 3，不会再触发重设。

## 时间线（正确路径）

- **t=0**：注入引信（基准时间定为 0，存储值 M+1）。t=0 无到期。
- **t=M**：注入五条创 M 条目（存储值 M+240 三条、M+242 两条，均已带高位）。无到期，时段结束于 M+1 终点刻——引信触发刻恰在终点，**不执行**，留成过期遗留。
- **t=J**：唯一到期的是引信（触发刻 M+1 已过）。消费中它给自己排 +2——schedule 路径发现距基准时间 J > 2^31−1，**重设基准时间到 J**：队内全部未来条目重算（存储值 M+240−J = 2，J+4 线为 4），自计划再按新基准入队（存储值 2）。随后种下一代猹0（出现时间 (J+2)&0xF = 0）。
- **t=J+2**（危急0 → 闰自计划7 → 松弛15）：危急0 清一代猹0；自计划复种二代猹2（(J+4)&0xF = 2）、给自己排 J+4；受害猹0 当刻消费（低四位 0）自清；观察者断言 层5猹2 == 层3猹2 过。
- **t=J+4**：二代自计划断言臂 层3猹2 == 层1猹2 过、链闭合；三条松弛15 清场。终态无猹。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 重设漏算（重算空转，存储值未随新基准更新） | J+2 时创 M 条目全不到期、危急0 未清一代——自计划断言臂 猹0 对 猹2，立即红 |
| 重设减错基准（按旧基准算差值、全部钳到 0） | 提前消费（偏序在 J 的第二批、全序在 J+1）：清除线不同余清不掉一代猹0，观察者断言 猹2 对 猹0——立即红；受害猹的错位属伴随现象 |
| 重设后新条目仍按旧基准算存储值（自计划被算到远未来＝复种丢失） | t=J+2 观察者断言 猹2 对 〇——立即红 |
| 自计划早到（J/J+1）或正在消费的批次被重设搅乱导致重复执行 | 断言臂 猹0 对 猹2 代差——立即红 |
| 危急0 清除线被重算错位 | 一代猹0 未清，自计划断言 猹0 对 猹2——立即红（现场与重设漏算行重合：两者同属"重算未生效"族，指认同一处代码，接受） |
| 重设把 J+4 线错算 | 参照或二代猹 2 错时消费不同余——幸存 |

## 设计要点与边界

- 窗口 [J, J+5) 五刻的低四位为 {14,15,0,1,2}：出现时间 0 仅在 J+2、2 仅在 J+4 同余，观察者故障路径种猹 (J+3)&0xF = 1 与两个清除刻均不同余——同余表干净。
- 引信与五条创 M 条目在重设前的存储值横跨 2^31 高位（M+1 低位、M+240/M+242 高位），顺带覆盖一次无符号堆序。
- **残余一（重设触发条件写成有符号不可测）**：有符号与无符号判断只在距离 ≥ 2^63 时分岔，量级不可达。
- **残余二（重算后忘记重建堆序不可见）**：本构造中重算是全队同减一个常数，相对序天然保持，堆不变式不破——该故障需混合钳制才可见，而钳制在本构造的规模下不发生。
- **残余三**：闰土复种的三条残余同样适用（同键窗口重复、观察者丢失沉默等），见 闰土复种.md。
