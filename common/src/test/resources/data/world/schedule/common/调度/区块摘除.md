# 样例：区块摘除

<!-- Claude Generated -->

针对"收尾时错误清空记账"一类实现：update 结束时把区块从记账集合整体清空（或按陈旧判据误判为空摘除）——中途入队让区块在本刻结束后队内仍有未来条目，被摘出记账的区块从此不再被 update 处理，里面**与中途入队无关的既有条目**也一并不再被消费。四个组合的记账结构同族（记账集合在共同基类），样例放 common。

## 布局与计划

列1 五层柱：层1 猹2（留存闰的下方参照＝一代状态）、层2 闰2、层3 种植位、层4 观察者闰3、层5 猹2（上方参照）；受害猹6 在 [1,1,2]。测试时段 `[0,7]`。

**全部创时 0** 是本样例的硬约束：时段内任何创时 ≥1 的同区块注入都会经记账集合的 add 把被摘区块重新挂回、掩盖故障——这也是受害线不能用"后补计划"善后的原因。创时核对：全部条目创时 0，(层2, 闰) 键为驱动条目【创0→t0】与自计划【t0→t2】首尾相接，无重叠。

| 条目 | 位置 | 时 | 创时 | 级 | 职责 |
|---|---|---|---|---|---|
| 留存闰 | [2,1,1] | 0 | 0 | 缺省 | 种一代猹2、给自己排 t=2——制造"本刻结束后队内仍有条目" |
| 观察者闰 | [4,1,1] | 1 | 0 | 缺省 | t=1 断言种植已发生 |
| 猹×3 | 层1/3/5 列1 | 2 | 0 | 松弛15 | 清参照与种猹（出现时间 2） |
| 受害猹 | [1,1,2] | 6 | 0 | 松弛15 | 与闰土自计划无关的既有条目 |

观察者取闰3：其故障路径种猹出现时间 (1+3)&0xF = 4，避开窗口内 2 与 6 两个清除刻，t=4 也无任何消费，不会被清除线误清而掩盖故障。

## 时间线（正确路径）

- **t=0**：留存闰消费——种一代猹2（出现时间 (0+2)&0xF）、给自己排 t=2。本刻结束时区块队内仍有六条未来条目（五条既有 + 一条中途自计划）。
- **t=1**：观察者上方=层5猹2 非〇走断言臂，断言 层5猹2 == 层3猹2，过。
- **t=2**：自计划断言臂 层3猹2 == 层1猹2 过、链闭合（一代即断言，无二代）；三条松弛15 同余清层1/层3/层5。
- **t=6**：受害猹6 同余自清。终态无猹。

## 故障与现场

| 故障 | 现场 |
|---|---|
| update 收尾清空记账 / 陈旧判据误摘区块 | t=0 之后区块不再被 update 处理：t=1/2/6 全部不发生——层1、层3、层5 三只猹2 与 [1,1,2] 猹6 集体幸存；**受害猹6 唯一指认"区块被摘"**（它与闰土自计划无关，闰土链的故障不会波及它），三只猹2 为副现场 |
| 留存闰未消费或种植未发生 | t=1 观察者断言 猹2 对 〇——立即红 |
| 自计划丢失/迟到 | t=2 断言未执行，种猹2 由清除线收走——此形态由闰土复种样例专责，本样例不重复验证 |
| 观察者上方为〇（层5 参照缺失类故障） | 观察者走种植分支，种下出现时间 4 的猹并给自己排 t=5——窗口内无 4 同余的清除，幸存 |

## 设计要点与边界

- 受害猹6 是本样例的关键设计：清晰标准要求红了能区分"闰链坏了"与"整个区块睡了"——前者只影响列1 的五层柱，后者连无关的 [1,1,2] 一起带走。
- 观察者放 t=1 而非 t=2：让"区块被摘"与"种植失败"两类故障在时间轴上分开露头（t=1 断言缺席 vs t=1 断言撞〇）。观察者取闰3 的同余论证见布局节，其故障行已入上表。
- 残余：自计划丢失在本样例不可见（清除线善后），由闰土复种覆盖；观察者自身丢失沉默的论证同閏土.md 残余四。
