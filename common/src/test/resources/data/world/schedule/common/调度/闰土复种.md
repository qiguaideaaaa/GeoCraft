# 样例：闰土复种

与闰土样例配套，消除其明示的三个不可见点：中途入队的正延迟自计划**丢失**、**早到**、以及第一代窗口内的**重复消费**。两件核心构造：故意在窗口中段清掉种猹，让"自计划缺席"在观察者断言上撞出〇；下方参照取**第二代**状态，让"提前执行"在断言臂上撞出代差。

创时表（同键存活区间）：(层3, 猹) 键——条目一【创0 → 消费 t2】、条目二【创3 → 消费 t4】，不相交；条目二创时必须 ≥3：注入检查先于当刻消费，创 2 会撞上仍在队内的条目一被去重拒绝。(层2, 闰) 键：驱动条目【创0→t0】、自计划一代【t0→t2】、二代【t2→t4】，首尾相接不重叠。同键探针在 t=1 注入，撞上存活期内的一代键——正确路径下被静默拒绝，这正是它要测的契约。

## 时间线（正确路径）

- **t=0**：复种闰消费——上方〇，给自己排 t=2，种下猹2（出现时间 (0+2)&0xF）。
- **t=2**（危急0 → 复种闰自计划7 → 观察者15）：危急0 清掉猹2（同余）；复种闰自计划见上方〇，给自己排 t=4、种下猹4（(2+2)&0xF）；观察者上方=层5猹4 非〇走断言臂，断言 层5猹4 == 层3猹4，过。
- **t=3**：注入 (层3,猹,时4) 条目二（键已随 t2 消费摘除，接受）。
- **t=4**（复种闰二代7 → 三条松弛15）：二代自计划上方=猹4 非〇走断言臂，断言 层3猹4 == 层1猹4，过——链在窗口内闭合；三条松弛15 同余清掉层1/层3/层5。终态无猹。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 自计划丢失（中途 schedule 被吞、或去重键被批末清理误删致自 schedule 被拒） | t=2 复种缺席，观察者断言 猹4 对 〇——**立即红**，带时间戳 |
| 自计划迟到（t=3 及以后） | t=2 时种植位还是 〇——同上立即红 |
| 自计划早到（t=0/t=1，含全序执行队列未隔离被直接塞进当刻执行流、偏序批内提前） | 彼时一代猹2 尚未被清，断言臂 猹2 对 下方参照猹4——立即红 |
| [t0,t2) 内自计划被重复消费（边遍历边插入的重复形态） | 第二次执行走断言臂 猹2 对 猹4——立即红 |
| 危急0 清除线错刻/丢失 | 一代猹2 未清，复种闰自计划走断言臂 猹2 对 猹4——立即红 |
| 二代种猹的清除线（创3 条目）被去重误拒 | 层3 猹4 无人清——幸存 |
| 去重键被双删或记账缺失（批末清理把 t0 自计划刚挂的键也删掉） | t=1 的同键探针被错误接受，重复闰土执行断言臂 猹2 对 猹4——立即红 |

## 设计要点与边界

- 同键探针按 README"同键探针豁免"纪律使用：删掉它不影响绿（敏感标准的显式豁免），其价值在于静默拒绝本身即被测的去重契约——键的存活期在四个组合下一致（打包偏序在 t2 消费前摘键、装箱偏序在 t2 出队摘键、两个全序在 t2 收集摘键，t1 时键均仍在）。
- 观察者按纪律构造：静止参照在上（永非〇，断言臂必达）、被观察位在下；其故障路径若种猹，出现时间 (2+1)&0xF=3 避开了窗口内全部清除刻 {2,4}，不会被清除线误清而掩盖故障。
- **残余一（观察者自身丢失=沉默）**：观察者是驱动器注入的普通条目，其丢失属基础调度故障、由其余全部样例覆盖；要与本样例的目标（中途入队条目丢失）同时漏检需两族故障叠加，接受。
- **残余二（二代自计划丢失不可见）**：t=4 无断言、清除线照常收场。同族故障在一代已检出，仅复合故障可漏检，接受。
- **残余三（[t2,t4) 窗口内二代被重复消费不可见）**：二代断言臂上下同为猹4，重复执行照过。窄窗接受。
- 时刻口径依规范裁定：中途正延迟条目自下一刻边界起受全部保证、必须恰在创刻+延迟执行（测试场景无更新量超限与区块卸载重载）；负或 0 延迟侧的口径与构造另见閏土样例。
