# 样例：严厉的鲁迅

<!-- 文档 Claude Generated，样例本身由作者设计 -->

鲁迅样例的跨区块加强版：十字复制两份、横跨两条区块边界。跨区块的"同刻内鲁先于猹消费"是全序调度器独有的保证，也是全序相对偏序多出的保证——本样例中对这条顺序真正敏感的位置是**南十字北臂**（它与心分属两个区块且属于猹4 线）；北十字的跨区块臂是猹5 线，顺序颠倒对它不可见，其职责限定为跨 x 边界的坐标还原与拨动定位。样例住在 `common/全序调度/`：偏序侧不运行它，它测的性质在偏序下本无保证。

计划结构与鲁迅样例逐条同构（三波：同刻十字、创时 5 的第二波、创时 16 的严重过期标记），时间线与各线算术见 `../调度/鲁迅.md`，本文档只记增量。

## 布局与区块分布

单层 18 行 3 列，原点 `[1,1,0]`（基点 x=−1）：列 1 落在 x=−1 的**负区块**，列 2、3 在 x≥0 侧。北十字占行 1–3（z=0..2），南十字占行 16–18（z=15..17）——前者横跨 **x=0 边界**，后者横跨 **z=16 边界**。全场横跨四个区块：

| 元件 | 位置 | 区块 |
|---|---|---|
| 北十字：西臂猹5 | [1,2,1] | (−1, 0) |
| 北十字：鲁4 心 + 北臂猹4、东臂猹4、南臂猹5 | [1,2,2] 等 | (0, 0) |
| 南十字：北臂猹4 | [1,16,2]（z=15） | (0, 0) |
| 南十字：西臂猹5 | [1,17,1] | (−1, 1) |
| 南十字：鲁4 心 + 东臂猹4、南臂猹5 | [1,17,2] 等 | (0, 1) |

两个鲁都是水平四方（鲁4），各拨自己的四臂——每个十字都有臂与心**不同区块**。

## 它验证什么

- **跨区块同刻优先级序**：t=3 两心（较高6）与八臂（缺省中上7）同刻到期。全序的全局队列按触发刻→优先级归并，两个鲁必然先于所有猹消费，不论各自身处哪个区块；偏序按区块批式处理时，臂所在区块若先于心被处理，该臂的自清判定就抢在拨动之前——同余判据用的是未拨动的状态。检出点唯一落在南十字北臂：它是猹4 线（判定用 3、拨动前是 4，颠倒必不同余）且与心跨区块。
- **负区块坐标参与关键路径**：西臂在 chunk −1，从区块坐标与区块内坐标还原绝对位置的算术（含负值一侧、符号扩展）直接位于消费顺序与拨动定位的必经路径上——坐标正负两侧互换、掩码截断负坐标一类解码故障在这里必然现形。
- **两轴分工**：北十字横跨 x 边界、南十字横跨 z 边界。坐标轴互换类故障会让两个十字呈现不同的幸存者组合——红了以后看哪个十字哪条臂，可反推断裂的是哪条轴。
- 严重过期标记与第二波清线的语义与鲁迅样例一致，但此处它们的"立即消费/准点清除"同样要跨区块归并成立。

## 故障与现场（增量部分）

| 故障 | 现场 |
|---|---|
| 跨区块优先级序失效（臂的区块先于心被处理） | 南十字北臂的猹4 在 t=3 消费时仍是 4 不自清，其后被拨成 3、t=16 再拨成 2——幸存猹2，即指认 z=16 边界两侧的顺序断裂 |
| x 正负两侧互换或负坐标解码错 | 西臂（x=−1）拨动落空或定位错乱——北十字西臂猹5 到 t=19 时不是 3，幸存 |
| z 的区块内坐标与区块号还原错 | 南十字北臂（z=15，与心隔着 z=16 边界）同理幸存 |
| 区块内型故障（顺序颠倒、标记失效、第二波丢失） | 与鲁迅样例的对照表相同，两个十字各自独立呈现 |
