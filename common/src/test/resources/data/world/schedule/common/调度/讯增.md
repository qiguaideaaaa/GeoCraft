# 样例：讯增

<!-- Claude Generated -->

验证讯方块（增一）与单面方位下标，并用"消费后同位再入队"探测入队去重集的残留：条目消费后，同一 (坐标, 方块) 必须能再次入队。

## 布局与计划

单层两格 `讯e 猹f`（讯e = 东向增一，东即列 +1），世界时间从 0 起，测试时段 `[0,18]`：

| 位置 | 方块 | 创时 | 时 | 含义 |
|---|---|---|---|---|
| [1,1,1] | 讯 | 0 | 1 | 第一次拨动 |
| [1,1,1] | 讯 | 3 | 5 | 第一次消费后同位再入队——去重残留探针 |
| [1,1,2] | 猹f | 0 | 17 | 计数器，清除刻低四位为 1 |

## 时间线（正确路径）

- **t=1**：讯第一次消费，东邻猹 f→0。
- **t=3**：第二条讯入队。第一条已消费出队，去重集应已放行同键——入队成功。
- **t=5**：讯第二次消费，猹 0→1。
- **t=17**（低四位 1）：猹的计划消费，状态恰为 1，命中自清。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 去重集残留（消费后未移除键，第二条被误拒） | 只增一次，t=17 时猹为 0——幸存 |
| 任一次讯触发丢失 / 重复 | 终态 0、f 或 2，均不同余——幸存 |
| 讯误作减一（与鲁语义颠倒） | f→e→d——幸存 |
| 方位错误（拨到东以外或无动作） | 猹保持 f——幸存 |
| 猹被提前消费 | 条目耗尽，t=17 没有计划再来清除——幸存 |

## 职责边界

首个使用讯与单面方位下标的样例；四方/六面方位由鲁迅样例覆盖。去重探针只验证"消费后可再入队"，同一条目在队内的重复入队拒绝（返回 false）无外部可观测现场，不在覆盖范围。

窗口 `[0,18]` 超过 16 刻，逐点验算同余：猹的状态序列 f →0（t=1）→1（t=5），各状态存续期内与状态同余的时刻仅清除刻 t=17 一个，错时消费必不同余。
