# 样例：过期即触

<!-- Claude Generated -->

验证入队时名义触发刻已过或恰为当刻的计划立即消费，且正常的未来计划不被这套"立即"机制波及。

## 布局与计划

单层网格，世界时间从 100 起，测试时段 `[0,3]`（更新 t=100、101、102 三刻）：

| 位置（层,行,列） | 方块 | 时 | 含义 |
|---|---|---|---|
| [1,1,1] | 猹4 | 95 | 过期 5 刻 |
| [1,1,3] | 猹4 | 99 | 过期 1 刻 |
| [1,2,2] | 猹4 | 100 | 恰为当刻 |
| [1,2,1] | 猹6 | 102 | 未来对照刻 |

四条计划均在 `创时 100`（首刻）入队。前两条 delay 为负，打包侧存储的 delay 被归 0；第三条 delay 恰为 0，存储值本就是 0——三条都在 t=100 消费——此刻低四位为 4，三只猹4 自清。对照刻在 t=102（低四位 6）消费，猹6 自清。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 负值归 0 失效（截断成错误的远未来值） | [1,1,1] 与 [1,1,3] 两只猹4 幸存（当刻那条 delay 本就是 0，不经过归 0 处理） |
| 负 delay 被直接拒绝入队 | 对应位置的猹4 幸存 |
| 消费迟于当刻 | 错过唯一同余刻，猹4 幸存 |
| 忽略 delay / 存储值恒 0 / baseTime 取错等"当刻全消费"型退化 | 对照刻被提前到 t=100 消费（低四位 4≠6 不清除，条目已耗），猹6 幸存 |

对照刻是本样例的关键区分手段：没有它，一切"把入队的东西当刻全消费"的退化实现都与正确行为不可区分。

## 职责边界

- 过期幅度只到 −5；时间差装不进 int 的"严重过期"（`Integer.MIN_VALUE` 压缩路径）由 `鲁迅` 样例覆盖；
- 三只猹4 共享消费刻，无法区分彼此的消费顺序——顺序不在本样例职责内。
