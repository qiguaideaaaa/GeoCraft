# 样例：閏土

<!-- Claude Generated -->

第一个针对设计规范明确规定的对象——执行中途 schedule 的**负延迟**条目——的样例。规范对它自己的时刻与顺序全面豁免（当刻消费与下一刻消费两态皆合法），样例要验证的是另一面——这次入队的**动作本身不得破坏既有同刻计划刻的顺序**。负延迟条目在打包侧归 0 后存储值极小、入队即排到堆顶，是"消费循环边遍历边插入"类故障的最强搅动源。

## 布局与计划

两条线：列1 的五层柱——层1 猹8（閏土下方参照）、层2 閏8（延迟 −8，最大幅度）、层3 〇（种植位）、层4 观察者闰1、层5 猹8（观察者上方参照）；受害线（层1 列2、3）——讯e 指向猹f，探测同刻顺序是否被搅动。测试时段 `[0,9]`。

| 条目 | 位置 | 时 | 创时 | 级 | 职责 |
|---|---|---|---|---|---|
| 閏土 | [2,1,1] | 0 | 0 | **危急0** | 本刻第一个消费：给自己排 −8、种猹8 |
| 讯e | [1,1,2] | 0 | 0 | 中下8 | 把猹f 拨成猹0 |
| 猹 | [1,1,3] | 0 | 0 | 松弛15 | 当刻消费拨后的猹0（同余自清） |
| 观察者闰 | [4,1,1] | 2 | 0 | 缺省中上7 | t=2 断言种植已发生 |
| 猹×3 | [1,1,1]/[3,1,1]/[5,1,1] | 8 | 0 | 松弛15 | 清两参照与种猹（出现时间 8） |

种猹出现时间 = (0 + (−8)) & 0xF = **8**，与层1/层5 参照一致。创时表：全部创时 0，无同键冲突；(层2, 闰土) 键——驱动条目【创0→t0】、自计划【t0→t0 或 t1】，t0/t1 两刻无其他同键注入（纪律三前提之三）。

## 时间线（正确路径，二态）

- **t=0**（危急0 → 中下8 → 松弛15）：閏土先消费——给自己排延迟 −8 的计划（触发刻在环上遥远过去，打包侧存储值归 0），随后种下猹8；讯把猹f 拨成猹0；猹0 的计划当刻消费（低四位 0）自清。
- **自计划的两个合法结局**：偏序/装箱在 t=0 的后续批次把它再次收集，全序把它留到 t=1 收集——两种时刻下走的都是断言臂（上方=种下的猹8 非〇），断言 层3猹8 == 层1猹8，层3 在两刻之间无人触碰，**两态同绿**。样例不断言它落在哪一刻（规范豁免）。
- **t=2**：观察者上方=层5猹8 非〇走断言臂，断言 层5猹8 == 层3猹8——种植确已发生（前提检查线）。
- **t=8**：三条松弛15 同余清掉层1/层3/层5。终态无猹。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 消费循环边遍历边插入（存储值 0 的新条目插到堆顶导致跳项/错位） | 讯被跳过→猹f 消费时 f≠0 幸存；猹0 计划被跳过→猹0 幸存；讯被重复→猹1 不同余幸存——受害线位置唯一指认 |
| 中途条目挤占既有条目名额（先数到期数再消费的写法） | 猹0 的计划被挤到 t=1，1≠0——猹0 幸存 |
| schedule 就地递归执行 | 閏土源码 schedule 先于种猹：递归时上方仍是〇，无限复种并反复给自己排计划——栈溢出，测试当场崩溃报错 |
| 消费中对集合迭代不当（装箱 for-each 类写法） | ConcurrentModificationException，当场崩溃报错 |
| 閏土未被消费或种植未发生 | t=2 观察者断言 层5猹8 对 〇——立即红 |
| 观察者上方为〇（层5 参照被误清一类故障） | 观察者走种植分支：种下出现时间 (2+1)&0xF=3 的猹并给自己排 t=3；t=3 断言臂 层5猹3 对 层3猹8——立即红 |

## 设计要点与边界

- 閏土取危急0 让搅动发生在同刻批的**最前端**，其后的讯、猹两条既有条目全程暴露在这次插入的影响下；取 −8 幅度最大，打包存储值归 0 的路径也一并覆盖。
- 三前提纪律逐条落实：合法消费必落断言臂（−8 的种猹出现时间 8 与合法执行窗 {0,1} 永不同余，上方必非〇）；下方参照在 t0/t1 间不变；两刻内无同键注入。
- **残余一（负延迟自计划丢失/存储值下溢成远未来不可测）**：条目缺席时断言臂不会失败，快照断言只看方块状态、看不出条目是否仍在队内，结构性盲区（见 README 盲区节）——本样例的观察者只验证"种植发生过"，验证不了"自计划条目还在队内"。
- **残余二（[t0,t1] 内自计划重复消费不可见）**：断言臂上下同为猹8，重复执行照过。窄窗接受。
- **残余三（"先入队再就地执行"变体写法可能全绿）**：先正常入队、再当场执行一遍的写法，第二次执行走断言臂通过、真条目次刻又被正常消费——上下仍相等，漏检。明示接受。
- **残余四（观察者自身丢失=沉默）**：观察者是驱动器注入的普通条目，其丢失属基础调度故障、由其余样例覆盖；与本样例目标同时漏检需两族故障叠加，接受。
