# 样例：跨零

验证世界时间越过 2^64≡0 归零点时，调度、到期判定与消费全程不受影响。时钟逐刻 +1 自然归零，不做任何跳跃。

## 布局与计划

单层三格，世界时间从 T = 2^64−3 = 18446744073709551613 起，测试时段 `[0,6]`（终点 T+6 归零为 3，`!=` 环判定恰执行 6 刻）。三条计划均首刻入队：

| 位置 | 方块 | 时 | 触发刻低四位 |
|---|---|---|---|
| [1,1,1] | 猹e | 2^64−2（归零前） | e |
| [1,1,2] | 猹0 | 0（恰在归零点） | 0 |
| [1,1,3] | 猹2 | 2（归零后） | 2 |

窗口内六个时刻的低四位依次为 d、e、f、0、1、2，两两互异，不存在低四位相同的两个时刻。YAML 中的环上大数按无符号十进制书写，由测试 YAML 构建器解析。

## 故障与现场

| 故障 | 现场 |
|---|---|
| 入口以无符号绝对比较判过期（`compareUnsigned(时, 当前)`） | 归零前入队的"时 0 / 时 2"被误判过期提前消费，猹0/猹2 幸存 |
| 消费早/迟一刻及以上 | 对应猹幸存 |
| 任一条计划丢失 | 对应猹幸存 |

## 职责边界

与 `符号翻转点` 镜像互补，注意分工的不对称：**"有符号绝对比较"这一故障在本线数值上恰好产生正确行为**（窗口的有符号值从 −3 递增到 2，中途未跨过有符号断点 2^63，有符号序与环序巧合一致），由符号翻转点线负责；本线独家负责"无符号绝对比较"。归零点同样不进入队列内部算术（`0 − (2^64−3)` 的减法在环上运算后自然等于 3），内部无符号比较由 `packed/调度` 的重设基准时间与大存储值样例覆盖。
